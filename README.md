# MmOrganized

An AI-powered memory capture and recall app, with complete control over your data and zero vendor lock-in. [Click here to visit](https://mmorganized.vercel.app).

## Software Stack

* **Framework:** Next.js (Full-Stack)
* **Language:** TypeScript / JavaScript
* **Authentication:** Better Auth (Google & GitHub OAuth)
* **Database & ORM:** PostgreSQL, Drizzle ORM
* **UI Components & Styling:** 
  * Tailwind CSS
  * Shadcn UI
  * Motion (Framer Motion)
  * Lucide React (Icons)
* **Payments & Billing:** Razorpay (Usage-based / Credit-based system)
* **Real-Time Notifications:** Pusher
* **AI Integration:** Vercel AI SDK
* **Architecture:** Multi-tenant SaaS
